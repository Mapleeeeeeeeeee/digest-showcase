Claude Meetup x Gaming  
  
昨天我在台北協助舉辦了一場以遊戲為主題的 Claude meetup。我和 Evan Webb 一起籌辦，\[1\]他是一位遊戲設計師，之前在 Activision 工作過。  
  
我最近剛好巧遇他，很有緣分，我們就開始聊到一起辦這場 meetup。我自己也喜歡玩遊戲，加上我們兩個都認識一些遊戲產業的開發者，所以才能一起把這場 meetup 辦起來。  
  
我自己昨天玩得超開心！  
  
簡單介紹一下這次的參加者：我們有 170\+ 人報名，其中 52% 每天都在用 Claude Code、21% 是創辦人，還有 24% 說他們想做遊戲。  
  
在 Luma 報名表裡，我問了大家心目中最喜歡的遊戲，《League of Legends》拿下第一名，而《Age of Empires》這類策略遊戲則是最大的遊戲類別。也有一些很有趣的回答，像是 Polymarket，還有人生本身。  
  
因為 Evan 來自遊戲產業，也參與開發過很多款遊戲，他一開場就說明遊戲開發其實是一連串的交接：概念美術先畫出東西，建模師把它建出來，綁定師架好骨架，動畫師讓它動起來，最後由設計師把它放進遊戲裡。  
  
他談到 AI 現在怎麼參與這條遊戲開發鏈，以及這次每位 demo 講者會如何展現不同類型的 AI 影響：  
  
1/ AI 在其中一個步驟。讓這條鏈裡的單一工作變得更快或更簡單，例如加速 3D 建模或動畫的工具。  
  
Jack Kelly\[2\] 用 Claude 加速重建自己 app 的各個步驟，後來才發現真正的瓶頸是產品方向，而不是程式碼。  
  
2/ AI 在步驟與步驟之間。也就是這些工作之間的交接，通常都是瑣碎又雜亂的工作。  
  
例如動畫師需要骨架用特定的方式設定好，所以綁定師得先幫他們準備好。另一個例子是用 AI 清理原始的動作捕捉資料，讓動畫師可以直接開工，不用先花時間修資料。  
  
Eric Khun\[3\] 則是用 Claude 處理從做出遊戲到吸引玩家之間的工作，包括行銷影片和 SEO。  
  
3/ AI 完全取代既有工具。改變整個遊戲製作的流程，而不只是加速舊流程裡的某些部分。  
  
他預告會有一位講者聊到這個，就是 Warrick Buchanan，\[4\]他打造了自己的引擎和專為 agent 設計的程式語言。Warrick 完全跳過現有的工具，讓 Claude 協助他從零開始打造。  
  
✚ Jack Kelly：找到真正的瓶頸  
  
Jack 是 CD Projekt RED 的資深工程師，過去四年半都在做 Unreal Engine、多人連線和 netcode。  
  
他在波士頓長大，搬來台北之前住過舊金山和紐約。他目前正在做 Naisu，一款遊戲剪輯 app。  
  
他在 2021 年和朋友一起開始做 Naisu，主要是做給自己用。某天晚上打完《Valorant》之後，他想把前一晚的片段全部看一遍，在 Discord 上笑大家打得有多爛，於是就開始了這個剪輯專案。  
  
這個專案停擺了兩次，一直到 2025 年他想學 Rust，才把它重新撿起來，當作學這個程式語言的方式。他把 agent 當成家教，讓它們在他手寫程式碼時考他 \(想學 Rust 的人，他推薦讀官方的 Rust 書\[5\]\)。  
  
透過這樣的練習，他最後重寫了整個 app，一次 commit 了 240,000 行，他並不推薦這樣做 \(「commit 要拆開」\)。  
  
不過重寫完成之後，他又撞上了之前讓專案停擺的同一道牆：他不知道 Naisu 下一步該做什麼。這比較是產品問題，而不是程式問題。  
  
Sunny Li，\[6\]Jack 的太太，也是介紹我認識 Jack 的朋友。她是產品設計師，所以幫他把願景磨得更清楚，雖然一開始有點不情願。我覺得這很可愛，讓我想到 Replit 的創辦人們。  
  
總之，他們建立了一套像精實團隊的流程：Jack 寫技術文件，Sunny 用 Figma 做設計，再把所有東西丟回給 Claude 來實作。  
  
在現場 demo 中，他展示了一個把多個片段合併成一條時間軸的功能，他說如果自己做至少要花三個月，但有了 Claude，他很快就做出來了。  
  
他分享了自己的心得和建議：把你的 prompt 做版本控制，這樣你可以看到 agent 檔案裡改了什麼。不要把待辦清單放在腦袋裡。  
  
還有，當你的計畫準備好了，不要按下 enter 就走開。坐下來好好讀 diff，因為那終究是你的 codebase。  
  
最後他分享了一些對遊戲產業的想法，指出很多大型科技公司的根源都和遊戲有關，像是 NVIDIA 和 Apple \(最初的《Halo》是 1999 年 Steve Jobs 在 Macworld 上首次發表的，當時它還是一款即時戰略遊戲\)。  
  
他說最重要的是讓遊戲好玩，而且做遊戲是一門藝術。「你沒辦法用『好玩』來訓練模型。」  
  
他秀了一張《Quake》的截圖，那是他從小玩到大的遊戲，他也承認畫面可能有點醜，但對他來說，那就是藝術，因為背後有很多回憶和情感。接著他秀了一張《The Witcher 3》的截圖，這也是我個人心目中最喜歡的遊戲之一，作為另一種同樣美麗的例子。  
  
Naisu 還沒正式上線，但你可以在 naisu\.gg 加入候補名單。\[7\]  
  
✚ Eric Khun：從做遊戲到吸引玩家  
  
Eric 是法國人，在台灣住了好幾年。他說他兩個文化的料理都喜歡，然後放了一段他把可頌泡進牛肉麵裡的影片，全場都笑翻了。  
  
說到他的職涯，他在社群媒體管理平台 Buffer 待了 11 年，今年 5 月離職，全職投入 antics\.gg，\[8\]一個讓任何人都能和朋友一起做、一起玩多人連線遊戲的平台。他用 Claude Code 大約 14 個月，從一開始就用它來做遊戲。  
  
Eric 一開場就請大家掃 QR code，結果現場 50\+ 人一起玩起他的遊戲，那是他前一天特地為這場 meetup 做的畫畫遊戲。這個開場真的很好玩。\[9\]  
  
他這場演講的重點是：寫程式已經不是最難的部分了，難的是 distribution，也就是讓產品被看見。  
  
所以他大部分的時間都在講他怎麼用 Claude Code 吸引更多人來玩。他的一些心得：  
  
✚ 他讓 Claude 去分析 TikTok 和 Instagram 上表現最好的影片，把它們成功的原因寫下來，從開頭的 hook、文字到格式都有。接著他讓 Claude 去玩他自己的遊戲，用這些格式做影片。  
  
✚ 因為你永遠不知道哪個平台會紅，所以他每個平台都發。有時候一篇貼文在一個地方沒人理，在另一個地方卻爆紅。  
  
✚ 在搜尋方面，他認為要被 ChatGPT 這類 AI 工具找到，關鍵還是好的 SEO \(他提到 ChatGPT 的搜尋很依賴 Bing，所以在 Bing 上的排名也很重要\)。他會用 Google Trends 和關鍵字工具找競爭比較低的主題，而不是去搶最競爭的那些。  
  
✚ 他也用 Claude 把朋友的 Android app 用 Swift 搬到 iOS 上，方法是讓它把原版 app 的每一個流程都走過一遍。  
  
最後他談到為什麼他覺得現在是自己出來做的最佳時機，也邀請大家參加他每週舉辦、給在做自己專案的人參加的 hackathon，叫做 Hackapei。\[10\]你可以在 antics\.gg 找到他的遊戲。  
  
✚ Warrick Buchanan：沒有極限  
  
Warrick 在遊戲業待了很久，參與過 PC、PlayStation、Xbox 和手機平台的作品，包括《Stronghold》、《Assassin’s Creed》和《Candy Crush》等系列。  
  
他也是出版過書的技術作者，在《Game Programming Gems》系列中發表過文章。他現在是 Spacebrainz 的 CEO，\[11\]這是一家 AI 研究公司，專注探索用 AI 創作遊戲和互動娛樂的新方式。  
  
Warrick 一開始先展示了今年的進展有多快。今年稍早，AI 還只能做出粗糙的 3D 物件。\[12\]  
  
到最後，他展示了 Opus 5\.5 像人一樣在雕塑 app 裡移動游標，雕出一個 3D 模型。\[13\]  
  
他提到以前那支 Will Smith 吃義大利麵的 AI 影片，並說在 3D 和空間理解上，我們早就遠遠超過那個階段了。  
  
他特別提醒了一件事。目前它比較適合當作探索點子的生成工具，而不是精準的製作工具。  
  
如果你給它一個很精確的目標，你可能會花很多時間試著讓它對上。不過對藝術家來說，他認為這是放大自己風格的方式，而不是取代他們。  
  
其中一個 demo 拿了一種特定的筆觸風格，做出那種風格的動畫角色。\[14\]  
  
接著他展示了幾款遊戲。其中一款是類似《Dark Souls》的遊戲，大約只用了三個 prompt，該有的敵人和戰鬥系統都有，而且沒有用 Unreal 或 Unity 這類現有的引擎。  
  
另一款是他在忙其他事情的同時，花了大約七週用 AI 做出來的電影感遊戲。還有一款是類似《GTA》的遊戲。那個賽博龐克城市的也超酷。\[15\]  
  
幾個月前，他對用 AI 開發遊戲時迭代太慢感到很挫折，於是開始打造一套專為 agent 設計的程式語言。他本來以為要到明年才做得出來。結果只花了大約兩天。  
  
那就是 Vibemaker，\[16\]一個為 AI agent 打造的遊戲引擎，他希望在今年底前免費釋出。  
  
他透過 Spacebrainz 想實現的更大願景是：有一天，我們分享遊戲和虛擬世界，會像現在分享圖片一樣簡單。  
  
✚ 一切都是為了好玩  
  
這三場 demo 都很精彩。雖然 AI 帶來很多挑戰，但能活在這個時代，從遊戲的角度去思考我們能用 AI 創造多少東西，真的很酷。  
  
這是我第一次辦全英文的 meetup。  
  
謝謝 Sunny 介紹我認識 Jack，也謝謝 Futureward 的 Jonathan Liao，\[17\]他透過一場和 Gold Card 相關的 meetup 介紹我認識 Eric，還要謝謝 Evan 介紹我認識 Warrick，更要大大感謝 Evan 和我一起籌辦這場活動，還當我的共同主持人。  
  
我想特別感謝我們的場地 Barcade，\[18\]他們送每位參加者一杯免費飲料，現場還有大型電玩、撞球桌、桌遊等等，讓大家在認識新朋友的同時也能一起玩遊戲。  
  
我非常推薦大家來這裡辦活動！
