🚀【120\+ 篇文章整理出來的 Claude Code 中文神文，最該看的人卻看不下去。】  
昨天在 FB 上看到一篇 Claude Code 最佳實踐的中文整理文，內容超扎實 — 整理了 120\+ 篇應用文章、30\+ 篇論文，還涵蓋 Anthropic 工程師（Boris、Thariq）的社群觀點  
  
（ 感謝 Maple Kuo分享，真的超級好文🙏  
  
本來想直接轉發給沒寫過 code 的朋友看看。結果點開仔細讀第一段，就發現不對 —— 滿滿英文術語（CLAUDE\.md、Subagents、Hooks、MCP…）會把他們直接嚇跑。  
  
明明每個概念背後都是日常早就在用的東西，但用英文寫出來就變成另一個世界。  
  
所以昨天我請claude把它翻譯成白話文 — 全程用「公司員工」「廚房品管員」「銀行金庫」這種比喻講，做了一份 50 張的 ELI5 簡報。  
  
先把 5 個白話重點給你 👇  
  
■  
  
📖 1\. CLAUDE\.md \= 給 AI 看的「員工手冊」  
  
你給 AI 的家規就像新人入職時的員工手冊。但你寫越多，他反而越不照做。  
  
超過 200 行，AI 的遵從率會從 76% 跌到 52%。最甜的長度是 60 行 —— 剛好夠講「我們這裡怎麼做事」，但不會多到他記不住。  
  
■  
  
🛠️ 2\. Skills \= 抽屜裡的「專業手冊」  
  
員工不用每天背所有專業知識，要用時拉開抽屜翻就好。Skills 就是這些抽屜裡的專業手冊。  
  
重點是書背標籤（description）要寫得夠精準，AI 才知道遇到什麼情境該翻哪一本。標籤模糊，再厚的手冊都用不上。  
  
■  
  
🤖 3\. Subagents \= 派助理出去查  
  
你是經理，你不該自己跑去搜尋整個 codebase。派個助理出去查，他回來只回報結論就好。  
  
一次最多可以派 4 個 subagent 並行跑。聰明的搭配（小助理 Haiku 跑檢索 \+ 顧問 Opus 做決策）可省 85% 成本。  
  
■  
  
🔄 4\. Hooks \= 自動守門員  
  
Hooks 就像餐廳出菜口的品管員。AI 要做的每個動作都會先經過他這一關。  
  
可以擋下危險指令（像 rm \-rf /），也可以在你存檔後自動幫你跑 lint、format。  
  
⚠️ 一個常見的坑：擋下動作要用 exit 2，不是 exit 1（很多人在這裡踩雷 —— 以為擋下了，結果其實放行）。  
  
■  
  
🏰 5\. Prompt Caching \= 水電費分時段  
  
跟水電費分時段一樣 —— 同樣的對話內容，快取命中時 $3 變 $0\.30，等於 10 杯咖啡只付 1 杯。  
  
⚠️ 但繁中使用者特別注意：千萬不要用 LLMLingua 那種壓縮工具來省 token，繁中會壞掉（衰退 25%\+）。要省，用 Caveman Rules 那種人工精簡才安全。  
  
■  
  
💡 一句話 Takeaway  
  
對「用過 ChatGPT 但沒寫過 code」的人來說：不用先看 120 篇英文文章，看完一個生活比喻就能開始用 Claude Code。  
  
員工手冊、抽屜、助理、品管員、水電費分時段 —— 全部都是你日常早就在用的東西。剩下的，只是花一個週末把對照關係建立起來而已。
