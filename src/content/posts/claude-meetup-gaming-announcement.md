幾個月前，我和 Jack 在一家很棒的義大利餐廳 Osteria Rialto 吃飯，發現 AppWorks 社群裡的創辦人 Evan Webb 跟朋友坐在另一桌。我們已經好多好多年沒見到他了，就過去打聲招呼。結果幾天後，我們去 PicCollage 辦公室參加 Jaime 的 chili 聚會，又遇到了 Evan！  
  
Evan 一直都在遊戲領域打造產品，聊著聊著，我們就想到可以辦一場以遊戲為主題的 Claude Meetup。非常感謝 Evan 和我一起共同主辦這場聚會。  
  
他介紹了他的朋友 Warrick Buchanan 給我認識。Warrick 參與過 PC、PlayStation、Xbox 和手機遊戲的開發，包括《Stronghold》、《Assassin's Creed》和《Candy Crush》等知名系列，也出版過技術書籍。他現在是 Spacebrainz 的 CEO，這家 AI 研究公司專注探索 AI 在遊戲與互動娛樂創作上的新可能。他會聊 AI agent 在遊戲開發上的潛力，並介紹他即將推出的免費遊戲製作軟體 Vibemaker，專為 AI agent 驅動的開發所設計。他會是這次的 demo 講者之一。  
  
–  
  
去年，我認識了一個很酷的女生 Sunny，她和另一半 Jack Kelly 一起搬來台灣。Sunny 是 lead product designer，待過 Facebook 和 Mad Realities 等團隊。Jack 是 CD Projekt Red 的資深工程師，這讓我超興奮，因為《The Witcher 3》大概是我心中最愛的遊戲，而這家遊戲工作室也開發了《Cyberpunk 2077》。他平常的工作涵蓋 Unreal、遊戲後端、多人連線 netcode 和遊戲伺服器，這次會是 Claude Meetup 的 demo 講者之一，來聊聊他的 side project Naisu，一款遊戲剪輯與錄影 app，即將在 naisu\.gg 上線。  
  
–  
  
在最早期的某一場 Claude Meetup，Jonathan Liao 主動聯繫我，提供 Futureward 的場地給聚會使用。他是台灣新創圈很棒的 connector，辦過各式各樣的活動，把大家聚在一起。我去參加過其中一場，認識了很多有趣的人，其中包括 Eric Khun。他是 Claude 的重度使用者，從一開始就用 Claude 做遊戲。他在 Buffer 待了 11 年，現在打造 antics\.gg，讓 vibecoders 在上面做多人連線遊戲。他會 demo 怎麼用 Claude Code 帶來更多用戶和玩家：SEO、社群媒體、影片生成，還有把麻煩的部分交給 coding agent 處理。哪些有效、哪些沒用，他都會講。  
  
–  
  
我選了一個也有遊戲可以玩的場地，demo 結束後歡迎留下來參加 mixer，認識有趣的人或一起玩遊戲。這次聚會全程以英文進行。報名連結在留言，名額有限，報名時記得寫一下你為什麼想參加。希望這會是一場好玩的社群聚會！
