# Ambassador 文章收錄原則

Claude Community Ambassador 的文章，只收活動回顧或有獨立資訊價值的內容。作者身分不代表每篇都要收錄。

- 保留有實際內容的活動回顧、工具教學、工作流程、實作心得及具體分析。
- 排除主要目的是報名、行程／場地通知、徵求場地、講者預告與短祝賀的文章。
- 混合文章讀全文判斷：需有不依賴參加該活動也能使用的方法或經驗，不能只因提到工具名稱就當成知識文章。
- 活動題目、講者簡介與未來將分享的主題，不等於會後內容。
- 依原文與轉分享完整內容判斷，不能只看標題；每篇記錄收錄或排除理由。

待收錄清單與已發布文章分開管理。未獲新增文章指示時，只更新清單。已發布的純預告移到非發布封存目錄，保留原文與來源，不再出現在首頁、作者頁或文章導覽。
