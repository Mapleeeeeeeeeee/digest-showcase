# 站內影片與部署更新

## 背景與問題
這批 Facebook 文章的全文及 74 張照片已保存，但 7 個影片附件仍需離站觀看。GitHub Pages 的 HTML 有十分鐘快取，舊訪客可能看不到剛部署的內容。

## 使用者角色與需求情境
讀者從展示櫃進入文章，希望直接播放影片；網站維護者發布更新後，希望訪客能取得新版而不必使用強制刷新。

## 設計意圖與業務規則
使用網站保存的 MP4 與瀏覽器原生控制列，避免依賴 Facebook 登入和短效影音網址。保留 Facebook 原文入口。
本批所有 7 個影片附件均須收錄，包括相簿中的影片，按原影片順序呈現。不自動播放、不強制靜音；影片無聲音軌時保留原本的無聲狀態。
既有完整原文、74 張照片及其順序不得改動。
保留 GitHub Pages，以部署版本偵測更新內容。前景頁面在載入、重新回到前景、及最長 15 秒間隔檢查新版本；有新版時自動載入新版網址，保留原路徑、其他查詢參數與錨點。
影片播放中延後自動刷新至暫停或結束，避免打斷觀看。離線或版本檢查失敗時維持目前頁面；同一新版不反覆重新載入。
本次功能安裝前已被瀏覽器快取的舊頁面不含偵測程式，無法由網站遠端清除；首次取得此版本後生效。GitHub Pages 快取標頭不宣稱已被改變，更新速度也不宣稱為毫秒級即時。

## 狀態
影片：未播放、播放中、暫停、結束、載入失敗。失敗時仍可透過原文入口觀看。
更新檢查：同版、新版待套用、播放中延後、請求失敗。隱藏頁面在回到前景後檢查。

## User Journey
### Journey 1：觀看影片
1. 從首頁開啟有影片文章，看到原文、照片與所有影片播放器。
2. 點播放，畫面及時間持續前進；有原音軌者正常保留聲音。
3. 暫停、拖曳至中段、繼續播放，皆正常；可開全螢幕或回原文。
### Journey 2：取得部署新版
1. 讀者開啟已安裝偵測功能的舊版文章。
2. 新版部署可取得後，前景頁面在下一次檢查自動刷新；保留閱讀路徑與錨點。
3. 播放中先保留頁面，暫停或結束後套用新版；同版不再刷新。

## 替代流程與錯誤情境
無影片文章不顯示空播放器。版本請求失敗、非預期回應或離線不觸發重新載入。
影片載入失敗時保留可用的 Facebook 原文連結。

## Out of Scope
更換主機、離線快取、Facebook 嵌入播放器、重新撰寫文章、修改過往已發布 commit。

## 整合點、規模與預期壽命
Astro 靜態網站與 GitHub Pages；本批 7 個影片，既有 43 篇文章。長期維護，訪客規模未知。

## Acceptance Criteria
- Given 任一批次影片 When 在文章播放 Then 能載入並播放、暫停與跳轉，無登入要求，7 個附件全數存在。
- Given 有照片與影片的文章 When 開啟 Then 既有全文及照片保持完整，影片順序符合來源。
- Given 已具偵測功能的舊頁面 When 新部署可用且沒有影片播放 Then 於最長 15 秒檢查週期或回前景時自動取得新版，保留位置網址參數，不重載迴圈。
- Given 影片播放中 When 偵測新版 Then 不打斷播放，暫停或結束後才刷新。
- Given 同版、離線、失敗或無效版本回應 When 檢查 Then 不誤刷新。
- Given 完成驗證 When 發布 Then 此次所有新增變更合成一個 commit，之前歷史保持不動。

## 開放問題
無。已獲使用者直接實作與發布授權；具體實作依最小必要方案決定。
