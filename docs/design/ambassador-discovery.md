# 影片封面與 Ambassador 識別

## 背景與使用者
讀者在首頁看到影片文章卻只看到「文字分享」占位，也無法辨認 Claude Community Ambassador 的文章。維護者需要知道 Facebook 還有哪些 Ambassador 文章尚未收錄。

## 設計意圖與業務規則
影片封面由已保存的原影片擷取真實畫面；原照片優先，無照片時才使用影片 poster。不得把影片封面加入原照片 images 或改寫原文。7 支影片都補 poster。
以精確 authorId 對應已核對的一手身分來源，集中登錄 Claude Community Ambassador 身分；不要只憑姓名或文章提及 Ambassador 就加徽章，也不把身分欄位複製到每篇文章。
徽章標示 Claude Community Ambassador，可開啟身分來源。這是作者的社群角色，不代表文章是 Anthropic 官方公告或作者是 Anthropic 員工。原有知識精華／社群活動分類保留。
首頁新增 Ambassador 篩選項，與現有分類／貼文種類同組擇一；搜尋、作者與日期條件繼續以 AND 疊加。卡片、文章頁、作者頁皆能辨認身分，無身分作者保持原樣。

## User Journey
1. 讀者在首頁或作者頁看到 Minecraft 等影片文章，卡片有真實截圖，進文後播放器也有同一影片封面。
2. 讀者點 Ambassador 篩選，只顯示名冊中作者的文章；搜尋／日期／作者可繼續縮小，清除條件可回全部。
3. 讀者開啟文章或作者頁，看到同一身分徽章並可追查來源。
4. 維護者取得漏文研究清單，每篇有 canonical ID、作者、日期與連結，並知道搜索範圍；已收錄／跨貼重複不可冒充缺漏。

## 畫面狀態與錯誤情境
無照片但有影片 poster：顯示 poster。無任何媒體：維持文字分享占位。無 Ambassador 匹配：不留空徽章或空白容器。查無符合文章：保留既有空結果提示。
Facebook 若需登入或不能讀取完整歷史，研究明示限制，不能把「未查到新增」寫成「全部同步」。不自動發文、加社團、改帳號或直接匯入未審查候選。

## Acceptance Criteria
- Given 本批7支影片 When 建置 Then 所有播放器有可讀poster，無照片的首頁及作者頁卡片使用真實截圖，原images完全不變。
- Given 已核對作者 When 看卡片、文章或作者頁 Then 顯示角色徽章與身分來源；未核對作者不誤標。
- Given Ambassador 篩選 When 疊加搜尋／作者／日期並清除 Then 正確顯示交集或還原全部，原分類仍保留。
- Given Facebook 搜尋結果 When 比對本站 Then 以canonical ID及跨貼內容排重，候選可逐篇查證，報告寫明覆蓋範圍。

## 規模、界線與授權
既有43文章、7影片、74原照片；此次僅修封面、加入角色與篩選及調查缺漏，不擅自把新候選匯入發布。使用者已要求修改與查找，沿用既有網站及發布方式。
